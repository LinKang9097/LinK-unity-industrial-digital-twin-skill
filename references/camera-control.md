# 相机控制

适用于自由移动、平滑旋转、俯视正交视角、场景漫游、设备漫游、定位、跟随、复位和视角切换。相机模块只负责视角行为，不负责业务数据真相。

## 职责边界

负责：

- 自由移动、右键旋转、滚轮前进后退。
- 平滑移动和旋转，默认过渡时间为 1 秒。
- 俯视视角，使用正交相机展示整体场景。
- 场景漫游，围绕场景重点区域转一圈。
- 设备漫游，随机选择设备并保持合适距离观察。
- 楼层视角，根据当前楼层配置平滑切换位置、旋转中心和俯视范围。
- 定位到设备、货物、库位或区域。
- 跟随 AGV、堆垛机、货物等目标。
- 视角复位和视角过渡。
- 限制相机移动范围，避免穿模或飞出场景。

不负责：

- 不解析实时消息。
- 不查询业务接口。
- 不改变设备或库存状态。
- 不在 UI 脚本里实现具体相机移动算法。

## 默认输入规则

默认鼠标操作应保持稳定，除非项目已有明确交互规范：

- 鼠标左键：无默认动作，预留给点击选择、框选、UI 或项目自定义操作。
- 鼠标右键长按：旋转相机。
- 鼠标滚轮：控制相机前进和后退，不只做视野缩放。

旋转中心按当前上下文决定：

- 未定位具体设备时，默认围绕整个场景模型中心旋转。
- 已定位到某个设备、货物、库位或区域时，默认围绕当前目标中心旋转。
- 已切换到某个楼层但未定位具体对象时，默认围绕当前楼层中心旋转。
- 目标丢失或取消定位后，旋转中心应回到场景中心或最近一次有效中心。

## 平滑过渡

移动、旋转、定位、复位、切换视角和进入漫游时都应使用平滑过渡，默认时间为 1 秒。可以按项目配置覆盖，但不要在多个 UI 脚本里硬编码不同时间。

推荐把过渡配置集中管理：

```csharp
// 中文注释：相机过渡配置集中定义，避免不同界面写出不一致的移动时间。
public sealed class TwinCameraSettings
{
    public float DefaultMoveDuration = 1f;
    public float DefaultRotateDuration = 1f;
    public float DeviceViewDistance = 8f;
}
```

跟随目标时可以持续平滑跟随，不必每帧重新启动 1 秒补间。高频目标移动应使用阻尼、插值或平滑跟随。

## 俯视视角

俯视视角用于查看全局布局、库区、输送线走向或设备分布。进入俯视时使用正交相机：

- 设置 `Camera.orthographic = true`。
- 相机从场景上方看向场景中心。
- 正交尺寸根据场景包围盒或配置值计算。
- 退出俯视时恢复透视相机、原始视角或目标视角。

俯视模式下可以保留平移和滚轮调整正交尺寸，但如果项目没有明确需求，先保持简单稳定。

## 漫游模式

漫游分为两类，不要混成一个含糊的接口。

### 场景漫游

场景漫游适合大屏、展厅和自动演示。相机围绕场景重点区域转一圈，观察中心通常是整个场景中心、库区中心或配置的重点区域中心。

实现建议：

- 使用配置好的中心点、半径、高度和时长。
- 相机沿圆形或分段路径移动。
- 移动过程中始终看向场景重点区域。
- 路径结束后可停在结束视角，或按项目要求循环。

### 设备漫游

设备漫游适合自动巡检和演示重点设备。相机随机选择设备位置进行漫游，但不能直接贴到设备上。

实现建议：

- 从已注册设备中选择可见、在线或配置允许漫游的设备。
- 根据设备包围盒或设备类型计算观察距离。
- 相机停在设备外侧合适距离，并看向设备中心。
- 设备间切换使用平滑移动和旋转，默认 1 秒或项目配置时间。
- 避免选择过小、隐藏、离线、未绑定模型或没有包围盒的对象。

设备漫游只负责相机视角，不改变设备状态、不触发设备动作、不拉取业务数据。

## 推荐接口

```csharp
// 中文注释：外部模块调用高层视角意图，具体移动逻辑由相机控制器实现。
public interface ITwinCameraController
{
    void Focus(string entityId);
    void FocusFloor(string floorId);
    void Follow(string entityId);

    void EnterTopView();
    void ExitTopView();
    void StartSceneRoaming(string routeId);
    void StartDeviceRoaming();
    void StopRoaming();

```

## 常见行为

- 自由相机：适合运维人员自主查看现场，默认左键无动作、右键旋转、滚轮前进后退。
- 俯视视角：适合查看整体布局、库位分布和设备区域关系。
- 楼层视角：适合多楼层场景切换时调整观察中心、旋转中心和俯视范围。
- 场景漫游：适合展厅、大屏和整体演示。
- 设备漫游：适合自动巡检和重点设备展示。
- 定位：适合从报警、任务、设备列表跳转到对象。
- 跟随：适合观察 AGV、堆垛机、关键货物或任务执行。

## 与 UI 的关系

UI 只触发相机意图，例如“定位到设备”“跟随 AGV”“退出跟随”。相机如何补间、如何避障、如何计算偏移，由相机模块内部处理。

## 验证重点

- 定位不存在的实体时不会报错。
- 跟随目标销毁或离线时能退出或降级。
- 相机过渡不会穿进模型内部。
- UI 打开弹窗时相机操作不会遮挡关键内容。
- 默认移动和旋转为平滑过渡，未配置时使用 1 秒。
- 未定位设备时围绕场景中心旋转，定位后围绕目标旋转。
- 切换楼层后相机能围绕当前楼层中心旋转，并按楼层配置调整视角。
- 俯视模式使用正交相机，退出后能恢复正常视角。
- 设备漫游不会把相机贴到设备表面，且始终看向目标设备。
